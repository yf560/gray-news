# GRAY

기사의 쟁점과 관점별 주장·근거·출처를 비교하는 모바일 중심 웹 프로토타입입니다.

## 화면 먼저 확인하기

ZIP을 받았다면 압축을 모두 풀고 **`미리보기.html`**을 브라우저로 여세요. 설치나 API 키 없이 미리 입력된 MBN 기사로 화면을 확인할 수 있습니다.

1. **쟁점과 관점 보기**를 누릅니다.
2. 관점별 카드를 비교하고 **근거·출처**를 펼쳐 원문 링크를 엽니다.
3. **기사 저장**을 누른 뒤 **저장한 기사**에서 검색·다시 열기·삭제·되돌리기를 확인합니다.

MBN 주소 `https://www.mbn.co.kr/vod/programView/1434541`의 결과만 화면 검수용으로 직접 정리해 넣었습니다. 실제 AI 분석 결과가 아니며, 화면에도 수동 작성 결과로 표시합니다. 다른 기사까지 임의 결과로 처리하지 않습니다.

저장 기록은 사용 중인 브라우저에만 남고 ZIP이나 GitHub에 포함되지 않습니다. 파일로 열었을 때 브라우저에서 저장을 제한하면 아래 로컬 서버 방식으로 확인하세요.

## 로컬 서버 실행

Python 3이 설치된 상태에서 프로젝트 폴더의 터미널을 열고 실행합니다.

```powershell
python server.py
```

Windows에서 `python` 명령을 사용할 수 없다면 `py server.py`를 사용하세요.

브라우저에서 [검수용 기사로 시작하기](http://127.0.0.1:8765/?review=mbn)를 엽니다. 위 MBN 화면을 확인할 때는 API 키가 필요하지 않습니다.

## 개발 시작

- **A · 백엔드 / LLM:** `server.py`, `test_server.py`
- **B · 프론트엔드 / 내 기록:** `index.html`, `assets/app.css`, 로고 파일

API 응답 예시와 작업 범위는 [개발 분업 및 착수 기준](개발-분업.md)을 먼저 확인하세요.

## 현재 상태

- 검정·회색 글라스 디자인과 각진 카드, 모바일·PC 반응형 배치
- URL·본문 입력, 로딩·취소·오류 복구와 작성 내용 유지
- 관점별 독립 카드, 근거 펼치기, 출처 링크와 중복 출처 정리
- 기사 저장·검색·재열람·삭제·삭제 되돌리기
- 브라우저 뒤로 가기·앞으로 가기, 결과 화면 새로고침 복원

프론트는 `POST /api/analyze`에 `{ "url": "...", "text": "..." }`를 전송하고, 합의한 `version: 1` 관점별 JSON을 표시합니다. 기존 텍스트형 분석 결과와 이전 저장 기록도 읽을 수 있습니다.

백엔드는 **K-EXAONE 2.5 + Tavily**를 사용합니다. URL·본문 입력과 `version: 1` 응답이 연결되어 있습니다.

PowerShell에서 키를 설정한 다음 실행하세요.

```powershell
$env:EXAONE_API_KEY = "발급받은 엑사원 키"
$env:TAVILY_API_KEY = "발급받은 Tavily 키"
py server.py
```

`.env`는 자동으로 읽지 않습니다. 키는 서버 환경변수에만 설정하세요. 검색·분석 흐름과 제한은 [엑사원 연결 안내](EXAONE.md)를 참고하세요. 실제 키를 이용한 연동 검증은 아직 수행하지 않았습니다.
