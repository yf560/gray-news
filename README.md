# GRAY

뉴스 기사의 쟁점과 다양한 관점, 관련 출처를 살펴보는 모바일 중심 로컬 프로토타입입니다. 사실의 진위를 판정하지 않습니다.

## 개발 시작

A는 저장소 담당자(백엔드·LLM), B는 팀원(모바일 화면·내 기록) 담당입니다. 담당 파일, API 응답 예시, 첫 작업 순서를 [개발 분업 및 착수 기준](개발-분업.md)에서 확인하세요.

## 실행

Python 3과 OpenAI API 키가 필요합니다. PowerShell에서 실행하세요.

```powershell
$env:OPENAI_API_KEY = '본인의_API_키'
python server.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. API 호출에는 비용이 발생할 수 있습니다.

## 현재 상태

- 기사 또는 URL을 입력하면 OpenAI 웹 검색을 이용해 분석 결과와 출처를 보여줍니다.
- 분석 기록은 현재 브라우저에 저장됩니다.
- 쟁점별 카드에 실제 결과를 연결하는 기능과 Tavily 연동은 아직 구현 전입니다.
