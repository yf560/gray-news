# GRAY 로컬 프로토타입

뉴스를 읽을 때 한 기사에 담긴 쟁점과 관련된 여러 관점 및 출처를 살펴보는 모바일 중심 로컬 데모입니다. 사실의 진위를 판정하지 않습니다.

구현 현황과 계획은 [구조와 하네스](구조와-하네스.md), 프로젝트 배경은 [기획 문서](프로젝트-기획.md)를 참고하세요.

Python 3으로 이 폴더에서 실행합니다. 별도 패키지는 필요하지 않습니다.

```powershell
$env:OPENAI_API_KEY = '여기에_본인의_API_키'
python server.py
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 같은 터미널에서 서버를 계속 실행해야 합니다. API 키는 대화에 보내거나 파일에 저장하지 마세요. 기본 모델은 `gpt-5.5`이며, 프로젝트에서 사용할 수 있는 모델로 바꾸려면 서버 실행 전에 `$env:OPENAI_MODEL`을 설정할 수 있습니다. OpenAI API 사용량 및 웹검색에는 비용이 발생할 수 있습니다.

사용자가 입력한 기사나 URL을 OpenAI Responses API로 전송하고, 웹검색 도구를 필수로 사용해 응답을 생성합니다. 검색을 통해 얻은 인용 URL은 응답에 실제 포함된 것만 표시합니다. URL의 기사 본문을 읽지 못할 수 있으므로 이 경우 본문을 직접 붙여넣어야 합니다.

분석 결과는 텍스트와 출처 목록으로 보여주는 초기 연결입니다. 쟁점별 카드와 출처 문장을 자동으로 연결하는 구조는 아직 구현하지 않았습니다. 분석 저장은 현재 브라우저의 localStorage에 저장되며 로그인과 사용자별 보호 기능은 없습니다. 서버는 127.0.0.1에서만 접속할 수 있도록 설계했습니다.

```powershell
python -m unittest -v test_server
```
